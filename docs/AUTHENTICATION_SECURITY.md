安全认证配置
============

管理页 `/security-authentication` 对应 `/api/admin/v1/security-settings`。查询只返回公开配置及密钥存在标记；保存需管理权限、CSRF 和 `If-Match`，旧版本写入返回 409。

会话使用带有效期的 Secure、HttpOnly、SameSite Cookie，关闭浏览器后仍可恢复。首页和登录页验证现有 Cookie 后自动进入对应工作台。默认关闭空闲过期，登录最长保留 30 天；可在安全认证中设置 0 至 43200 分钟的空闲期限及 1 至 365 天的最长期限。修改配置后，空闲期限立即生效，绝对期限用于新登录。已经因空闲过期而撤销的会话不会因放宽配置而恢复。浏览器只额外记录最近登录的身份类型，不在 JavaScript 存储中保存令牌。

启用二次验证后，管理写操作需要十分钟内的密码确认。前端在提交前显示验证对话框，服务端独立检查，不依赖前端判断。退出登录无需二次验证。

管理员密钥仅在生成时显示一次，有效期一年，绑定生成者当前的身份及实时权限。`GET /api/admin/v1/security-settings/admin-key` 返回是否已生成和到期时间，`POST` 生成或重新生成，`DELETE` 撤销。数据库仅保存摘要，重新生成及删除立即撤销旧密钥。自动化调用使用 `Authorization: Bearer <key>`，访问 `/api/admin/*` 管理资源；浏览器会话使用原有 Cookie 和 CSRF。禁止混合 Bearer、Cookie 和 Origin。密码/身份失效及权限撤销同样影响密钥。

人机验证使用 Cloudflare Turnstile。配置真实站点密钥和私密密钥后，登录、注册、找回密码和 OAuth 起始请求携带一次性令牌。后端调用固定的 Siteverify 地址并检查 hostname，失败或超时不放行。

OAuth 的 GitHub、Google、LinuxDo Client ID、Client Secret 和回调地址可在此页配置，无需重启。回调路径为 `/api/v1/auth/oauth/<provider>/callback`，必须使用 HTTPS。还需在网站设置中启用对应提供商。“身份绑定”决定是否允许新的第三方身份进入邮箱验证注册流程；已经绑定的身份不受此开关影响。待验证注册身份有效期为配置的小时数，密码重置链接仍为二十分钟。

私密密钥通过 `admin.identity_notification_key_file` 指定的 32 字节密钥使用 AES-256-GCM 加密。该密钥文件必须与数据库备份一同妥善保存；不要将其提交到仓库。字段留空保留已保存密钥，查询接口不返回原值。

登录请求同时受全局、来源和账号预算约束。重复错误凭证按来源累计；达到配置阈值后，开启“访问封禁”时拒绝该来源的后续认证。成功认证清除该来源的失败记录。经反向代理部署时，来源使用网关实际连接端，不直接信任客户端提交的转发头。

数据备份
========

备份页 `/data-backup` 连接 `/api/admin/settings/backups/*`。配置 S3 兼容存储后须通过写入、读取、元数据及删除探针验证，才能创建备份。手动与计划任务由后台执行，记录显示真实状态、错误、大小及 SHA-256。下载使用短期预签名地址；删除在后台移除对象后移除记录，计划备份受保留天数和份数约束。

导出程序依赖与数据库主版本匹配的 `pg_dump`，当前部署镜像安装 PostgreSQL 18 客户端。归档为 gzip 压缩的 SQL，使用一致性快照并保留业务数据及已发布统计。恢复应先在独立空库验证，使用同一版本的应用和 PostgreSQL；配置文件及加密密钥文件需单独备份。

计划与记录时间使用后端返回的部署时区，不再将本地时区的 Cron 标为 UTC。覆盖恢复和异步生图对象存储已接入执行接口，恢复的停机、回滚及密钥要求见 [数据备份](DATA_BACKUP.md)。

服务器验证脚本 `tests/deploy/security_backup_execution.cjs` 仅运行在 19444 的隔离数据库与对象存储测试服务。它验证真实导出、上传、下载摘要、删除以及安全认证执行，不使用真实第三方凭据。
