# Analysis Reports

Historical Codex/sub2api research is preserved separately from the gateway design.
Read [the English evidence summary](codex/EVIDENCE_SUMMARY.md) first.

source-archive/ contains original source documents as evidence attachments, including
Chinese-language originals. These are preserved verbatim rather than presented
as English project documentation. manifest.json records source-relative names
and SHA-256 checksums. No live credentials or raw authenticated captures are imported.

These reports describe the source workspace on 2026-09-17. They are not proof
that Ovload Gateway implements the behavior. Proposed migrations of Go/sub2api
settings do not apply directly to this new Rust project.
Original local paths and revision references are historical provenance, not
portable links or instructions to access another machine.

The project architecture and current ADRs take precedence for new implementation.
Do not convert client captures into claims about undocumented server-side risk controls.
