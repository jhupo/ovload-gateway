## Home: connections, quietly expressed
Use case: ui-mockup. Asset type: desktop landing-page concept, 1536 by 1024.
Brand: ovload. Minimal editorial AI gateway, warm near-white canvas, generous
whitespace, charcoal Inter typography, muted sage and one restrained lavender
accent. Left-aligned short headline, quiet primary action, fine curved lines
connecting applications through one central ovload node to OpenAI, Gemini,
Claude, and Grok wordmarks. A softly elevated login card below the fold.
Typography should be crisp and practical. Use very little copy; no component
labels, UI implementation explanations, neon grids, glowing orbs, sci-fi imagery,
fake terminal output, stock photography, or invented provider logos.

## User workspace: space to create
Use case: ui-mockup. Asset type: desktop user dashboard concept, 1536 by 1024.
Brand: ovload. Maintain the home palette, Inter/Noto Sans SC typography, quiet
Lucide-like outline icon style, restrained 12–16px cards, soft shadows. Compact
left navigation, personal greeting, three usage cards, a low green area chart,
a provider donut, a concise API key section and model preference selector.
Sparse copy, no paragraphs explaining controls, no giant decorative hero.
Clearly mark sample data once. Primary actions are visually distinct without glow.

## Administration: calm operational clarity
Use case: ui-mockup. Asset type: desktop admin dashboard concept, 1536 by 1024.
Brand: ovload. A refined dark slate variant of the same system: readable muted
text, thin borders, low-contrast surface separation, sparse lavender emphasis,
small green/amber status badges. Left navigation, request success/account/latency
metrics, compact area chart, provider donut and account table. Prioritize spacing,
typographic hierarchy, scanability and purposeful actions. Sample data is labeled
once. No neon, fake terminals, sci-fi gradients or instructional component prose.
